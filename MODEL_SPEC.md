# V3 Romano–Hennequin hybrid scaffold

## Status and boundary

This document describes the first untrained V3 scaffold on branch
`v3-romano-hennequin`. The authorized scope is structural, gradient,
checkpoint, loss-mask, effective-dynamics, and neural-geometry smoke testing.
No deterministic V3 training has been run. No neural-noise stage,
cerebellar removal, lesion, adaptation, or phenotype-matching objective is
implemented.

## Cortical dynamics

The cortical network has 200 ReLU units, time step 5 ms, and time constant
150 ms:

`tau*dx/dt = -x + Wrec*r + h + Wtarg*q + Wgo*g(t) + Ucb*c(t)`

with `r = ReLU(x)`. There is exactly one fixed recurrent matrix `Wrec`.
No recurrent matrix is selected or switched at go. Fixed baseline rates use
the deterministic lognormal-quantile convention with 5-Hz mean and 5-Hz
standard deviation. The fixed background drive is `h = r0 - Wrec*r0`.

## Single hybrid recurrent construction

A deterministic QR factorization of a seeded 200-by-200 Gaussian matrix
creates the orthonormal population basis
`Q = [Qprep Qmove Qbackground]`, with dimensions 10, 10, and 180.
The QR column signs are canonicalized from the diagonal of `R`.

In this basis, one block operator `B` contains:

- preparation block:
  `0.55*diag(linspace(0.70,1.00,10))`;
- movement block:
  `0.45*I + 3.0*u*v'`, where `u` is the normalized first-half indicator,
  `v` is the normalized second-half indicator, and `u'*v = 0`; this
  nilpotent feedforward term supplies strong non-normality;
- fixed preparation-to-movement coupling:
  `0.75*I` in the movement-row/preparation-column block;
- background block:
  `0.20*diag(linspace(-1,1,180))`.

The official `why-prep-2` matrix is hash-verified and used only as a scale
reference. The global multiplier is the smaller of:

1. the multiplier placing the V3 spectral abscissa at 90% of the reference
   spectral abscissa; and
2. the multiplier limiting the V3 Frobenius norm to 25% of the reference
   Frobenius norm.

The fixed neuron-coordinate matrix is constructed once as `Wrec = Q*B*Q'`.
Its realized normalization and matrix diagnostics are recorded by the smoke
test. `Qprep'*Qmove` is zero to numerical precision by construction, but
actual preparatory and movement activity is not constrained to be
orthogonal.

## Inputs and cerebellar pathway

- Targets are the persistent one-hot identities for
  `[-90 -45 0 45 90 135 180 225]` degrees at a 0.06-m radius.
- Cortex receives target identity directly through `Wtarg*q`.
- Cortex receives a target-independent 75-ms go pulse that is exactly zero
  before each trial's actual go time.
- The cerebellum receives target identity only.
- The target-conditioned desired cerebellar state is generated by a
  trainable 8→12 tanh→5 mapping.
- The five-dimensional state obeys
  `tau_cb*dc/dt = -c + c_target`, with `tau_cb = 150 ms` and `c(0)=0`.
- The cerebellum receives no go, elapsed time, target coordinates, target
  angle, desired/future kinematics, cortical state, velocity, or hand state.

## Output and task

The linear readout is `v = Wout*r`, with two components `[vx,vy]`.
Position is only the kinematic accumulation `p(t+dt)=p(t)+dt*v(t)`.
There are no joints, torques, mass, inertia, muscles, or other limb dynamics.

The instructed-delay grid is `500:10:700 ms`, with 600 ms canonical for V3
diagnostics. Each fixed-size trial runs through the maximum 700-ms delay,
500-ms movement epoch, and 200-ms hold, for 281 samples from 0 to 1400 ms.

## Fixed and trainable quantities

Fixed quantities are `Wrec`, the structural bases and block construction,
baseline rates/background drive, cortical and cerebellar time constants,
time step, and task geometry.

Trainable arrays are `Wtarg`, `Wgo`, `WcbHidden`, `bcbHidden`,
`WcbLatent`, `bcbLatent`, `Ucb`, and `Wout`. `Wrec` is absent from the
trainable-field list, packed optimizer vector, and Adam state.

## Initial behavioral objective

The first V3 objective inherits the final V2 behavioral logic without
performance-based retuning:

| Component | Weight |
|---|---:|
| Pre-go position | 200 |
| Full pre-go velocity energy | 100 |
| Final-150-ms pre-go velocity energy | 50 |
| Increasing movement-window endpoint urgency | 10 |
| Terminal position | 100 |
| Terminal velocity | 50 |
| Hold position | 100 |
| Hold velocity | 50 |
| Velocity effort | 0.001 |
| Activity regularization | 0.00001 |
| Trainable-weight regularization | 0.000001 |

The velocity normalization is 0.25 m/s. No PCA, participation-ratio,
alignment, principal-angle, covariance, empirical-trajectory, neural-state,
lesion-phenotype, prep-to-move-R², or cerebellar-removal term enters the loss.

## Analysis-only local dynamics and geometry

For a ReLU active-set mask `D(t) = diag(r(t)>0)`, the analysis helper computes
`A_eff(t) = -I + Wrec*D(t)`, ignoring the common `1/tau` factor. A changed
active set can change `A_eff` while the one fixed `Wrec` remains identical.
This calculation is never part of the objective.

Neural geometry uses deterministic target-averaged activity, per-neuron
normalization, and timewise across-target mean subtraction. The common
subspace dimension is `max(k95prep,k95move)`. Bidirectional variance-normalized
alignment and variance-captured curves are descriptive only. Smoke testing
uses five random-null samples solely to validate the null-analysis plumbing;
it is not a scientific null result.
